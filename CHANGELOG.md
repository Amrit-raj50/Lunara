## [0.1.0] - 2026-05-07

### Added
- Initial release of Lunara
- **Audio Lab**: Professional audio enhancement with noise reduction, voice boost, EQ clarity, and LUFS normalization
- **Video Studio**: AI background removal using MediaPipe, custom backgrounds, cinematic filters, skin smoothing, and light matching
- **NLE Workflow Editor**: Visual timeline editor for template-based video creation
- **Batch Rendering**: Process multiple videos with automatic captions and thumbnails
- **Live Preview**: Real-time preview of video effects before processing
- **Smart Captions**: AI-powered transcription using OpenAI Whisper with SRT export
- **Docker support** for easy deployment
- **MIT LICENSE** for open source distribution

### Features
- FastAPI backend with MongoDB integration
- React 19 frontend with Vite build system
- FFmpeg integration for media processing
- WebSocket progress tracking for long-running tasks
- Library management for processed assets
- Settings persistence for user preferences
